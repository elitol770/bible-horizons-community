# BibleHorizons community kit

This public repository is separate from the private application and deployment. Never copy private application files, credentials, user data, third-party assets, or internal reports into it. Do not add deployment credentials or deployment automation.

Preserve contributor ownership and attribution. Code is MIT; original scene data, documentation and artwork are CC BY 4.0 unless a file explicitly states otherwise. Do not invent permissions, Scripture, citations, historical certainty or reviewer approvals. Contributions are proposals; merging here never publishes a chapter or deploys BibleHorizons.com.

Keep the local viewer usable with keyboard controls, reduced motion and a non-canvas object list. Model inspection is not historical review. Run npm run check after changes. New chapter proposals need Bible and visual review before official integration. Untrusted contributions must never run with production secrets or on a self-hosted runner.
